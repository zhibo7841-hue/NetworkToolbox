# NetworkToolbox v0.1.0

Release notes draft for the first public release. This document does not create a GitHub Release.

## Title

NetworkToolbox v0.1.0

## Highlights

First public release.

Includes:

- Ping
- DNS
- TCP Port Check
- IPv4 Subnet Calculator
- Diagnostic Report
- Local History

The application also provides Network Information and Home / Tools / Settings navigation.

## Requirements

- Android 12 or later (API 31+)
- No account required
- Network test results and history remain local to the device

## Installation

Download the signed APK from the GitHub Releases page after the release is published.

The current project build reports `versionName = 0.1.0`. Release signing must be configured before publishing.

## Known Limitations

- Advanced tools are planned for future releases.
- No LAN Scanner yet.
- No Wi-Fi Analyzer yet.
- No mDNS or Wake-on-LAN yet.
- This release is a network analysis and troubleshooting assistance tool, not an automatic repair or definitive diagnosis system.
- A release signing configuration is not committed to the repository.
