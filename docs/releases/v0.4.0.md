# NetworkToolbox v0.4.0

NetworkToolbox v0.4.0 is prepared for final APK verification. It strengthens
the app's core diagnostic workflow while keeping network observations and
reports local to the device.

## 主要更新

### 自动网络诊断 Phase 2

Automatic Diagnostics now combines multiple local observations and focused
probes to provide:

- Evidence-based fault assessment.
- Possible-cause explanations.
- Practical troubleshooting recommendations.
- Progressive execution status and Retry / Verify.
- Conservative handling of timeouts, VPN, Fake-IP DNS, mobile gateways, and
  conflicting public probes.

A single timeout does not automatically mean that the Internet is unavailable.
An unresponsive gateway is not reported as a gateway failure when independent
public connectivity evidence is still healthy.

### 诊断报告

Diagnostic Report Phase 1 supports:

- Complete in-app reports.
- Local History snapshots and report reopening.
- Copying report text.
- Saving a PDF.
- Sharing a PDF.

Reports are generated on the device, require no account, and do not upload
diagnostic data.

### 其它改进

- History compatibility and diagnostic snapshot handling.
- PDF layout and Chinese / English / technical-token wrapping.
- Diagnostic UI clarity, privacy messaging, and release stability.

## 隐私

- No ads.
- No account required.
- Diagnostic data is processed locally by default.
- A report leaves the app only when the user explicitly saves or shares it.

## Compatibility

- Android 12 (API 31) or later.
