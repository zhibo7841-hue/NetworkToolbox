# NetworkToolbox v0.2.0

NetworkToolbox v0.2.0 expands the local, evidence-based diagnostic workflow
with enhanced Ping, DNS, automatic diagnostics, and LAN discovery.

## Major updates

### LAN Scanner

- Scan the current eligible LAN IPv4 range automatically, with a bounded /24
  safety limit.
- Scan a custom RFC1918 IPv4 start/end range of up to 254 addresses.
- See discovered local devices, the current device, and the default gateway
  while a scan progresses.
- Stop, rescan, or modify a completed scan range.
- Keep completed LAN scan summaries in local History.
- Benefit from bounded-concurrency performance improvements and TCP
  false-positive protections.

### Ping

- Use quick or continuous checks with IPv4, IPv6, or automatic protocol
  selection.
- Review current, average, minimum, and maximum latency, packet loss, and
  network-quality summaries.

### DNS Lookup

- Query A, AAAA, CNAME, MX, and TXT records with TTL details.
- Review system DNS results and advanced record details.
- See a clear notice when a result uses a special-purpose Fake-IP address.

### Network Diagnostic

- Run an automatic local-network, gateway, public-connectivity, DNS, and
  domain-access diagnostic workflow.
- Read understandable conclusions, possible causes, and prioritized
  troubleshooting suggestions.

### Other improvements

- Clearer Home network status for IPv4, IPv6, gateways, and configured DNS.
- Existing TCP Port Check, IPv4 Subnet Calculator, and local History remain
  available.
- Stability and usability fixes across diagnostics and LAN scanning.

## Requirements

- Android 12 (API 31) or later.

## Privacy

- No account required.
- No ads.
- Network diagnostic data is not uploaded.
- Results and History are stored locally, and app-local data does not
  participate in Android system cloud backup by default.
- Network probes are initiated only for user-selected checks; they do not
  upload diagnostic reports or LAN data.
